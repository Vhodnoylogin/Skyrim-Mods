# assets\ — невосстановимые исходники

Здесь лежит то, что **нельзя пересобрать по рецепту**: файлы `.blend` со скульптом,
вылепленная руками геометрия, готовые `.esp`, авторские текстуры.

В git это не попадает намеренно: он хранит двоичный файл целиком на каждое изменение
и различий не показывает — история распухает, а пользы от неё никакой.

**Отсюда обязанность: эта папка требует отдельной резервной копии.** Рецепты в репозитории
защищены историей коммитов, содержимое `assets\` — нет.

Порядок такой:

    assets\<что это>\            живая версия, с которой работаем
    assets\snapshots\<дата>-<что>.7z   слепок перед крупной переделкой

Слепок делается **перед** тем, как ломать работающее, а не после. Имя со связкой даты и
темы, чтобы через месяц было понятно, что внутри.

Если когда-нибудь понадобится настоящая история для двоичного — стандартный ответ это
Git LFS: git хранит указатель, сам файл лежит в отдельном хранилище. Но LFS осмыслен, когда
есть удалённый сервер и несколько человек; для одной машины версионированная папка со слепками
честнее и проще.
