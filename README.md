# Envoy Framework

Мост между Skyrim и внешними моделями. Одна служба владеет микрофоном, голосом и моделями;
моды в игре подписываются на результат вместо того, чтобы поднимать собственный движок.

Четыре канала:

| Канал | Что делает | Форма взаимодействия |
|---|---|---|
| `Listen` | распознанная речь игрока приходит в игру | поток, темы, аукцион |
| `Speak`  | игра просит озвучить реплику | очередь с приоритетом и прерыванием |
| `Ask`    | игра задаёт вопрос модели | запрос-ответ |
| `State`  | реестр состояния мира | публикация и опрос |

Первый срез реализует только `Listen` и `State` в объёме ядра. Остальное добавляется,
не трогая написанное.

## Принципы

- **Ни одной константы в коде.** Всё настраиваемое живёт в `config/envoy.default.json`.
- **Никакой привязки к редакции игры.** Признак — не «это VR», а «есть ли поставщик ключа».
  Поле без поставщика отвечает «неизвестно», а не подставляет ложь.
- **Ключ описывает вопрос, а не способ ответа.** `core.target.looked`, а не «перекрестье».
- **Детерминизм.** Ни один спор не решается порядком пробуждения скриптов.

## Раскладка

    contract/   публичный контракт: ABI, протокол, игровое API, пространство ключей
    config/     эталон настроек и схема проверки
    src/        плагин SKSE (C++, CommonLibSSE-NG)
    providers/  поставщики состояния
    papyrus/    скрипты мода
    esp/        квест-носитель
    tests/      прогон аукциона без игры
    tools/      сборка и раскладка в mods\

## Сборка

    tools/build-papyrus.ps1

Раскладка в `mods\` — `tools/deploy.ps1`. Запускать только при закрытой игре.
