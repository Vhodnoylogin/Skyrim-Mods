# morphbench: с чего начать

Записка для того, кто будет пользоваться верстаком, а не дописывать его. Устройство и правила
границы — в [README.md](../README.md).

## Что нужно

- Python 3.12 с пакетами `numpy` и `pillow` (без `pillow` нет растеризатора PNG).
- Аддон **PyNifly** в каталоге аддонов Blender: `%APPDATA%\Blender Foundation\Blender\<версия>\scripts\addons\io_scene_nifly`.
  Программа находит его сама; если он лежит в другом месте, путь задаётся ключом `pynifly`
  в `morphbench.json`. Своих разборщиков NIF и TRI у верстака нет и быть не должно.

## Запуск

Все команды идут из папки модуля:

    python mb.py <команда> <меш.nif> [ключи]

Файл морфов `.tri` подбирается рядом с мешем сам (то же имя без суффикса веса `_0`/`_1`);
явно — ключом `--tri`. Ко всякой команде подходит `--json`: тот же ответ машинно.

| Команда | Что отвечает |
|---|---|
| `summary`, `shapes`, `bones`, `morphs`, `empty` | что за меш, его части, кости, ползунки и пустые морфы |
| `missing <nif> A B C` | каких ожидаемых ползунков в файле нет |
| `strain <nif> [--morph X]` | где морф растягивает или рвёт поверхность |
| `layers <nif> --morph X [--adjacent] [--base S]` | следуют ли оболочки за кожей; `--adjacent` оставляет только те, что обязаны |
| `binding <nif> --morph X [--shape S]` | каким костям принадлежит то, что морф двигает, и какие кости брошены |
| `focus <nif> --bone B \| --morph X \| --shape S` | наведение камеры числами: центр и радиус |
| `render <nif> --out кадр.png [...]` | кадр PNG |
| `sheet <nif> --out папка [...]` | несколько ракурсов подряд |
| `web <nif> --out страница.html [...]` | самодостаточная смотрелка в браузере |

Общие ключи `render`, `sheet` и `web`:

    --view front|side|back|top|below|quarter    ракурс из настроек
    --look 40,15                                произвольный ракурс: поворот,подъём
    --colour bone|morph|strain --morph X        раскраска: по костям, по сдвигу морфа, по растяжению
    --slider X=1                                значение ползунка; ключ повторяем
    --only body,head                            какие части показывать
    --zoom 2   --pan=5,-3   --size 900x900      масштаб, панорама, размер кадра
    --focus-bone "L Finger" | --focus-morph X | --focus-shape head    смотреть на часть тела

Пары чисел с минусом впереди пишутся через знак равенства: `--pan=-5,3`, `--look=-10,5`.
Подстрока в `--focus-bone` объединяет все подходящие кости: `L Finger` — все пальцы левой лапы.

## Настройки

`morphbench.json` рядом с `mb.py` создаётся при первом запуске; ключи, которых в старом файле
нет, дописываются сами. Что там менять чаще всего:

| Ключ | Смысл | По умолчанию |
|---|---|---|
| `baseShape` | имя базовой части — кожи, за которой следуют оболочки | `body` |
| `contactRadius` | в каком радиусе от кожи вершина оболочки считается лежащей над ней | 6 |
| `minContact` | доля вершин над сдвинутой кожей, с которой оболочка обязана следовать | 0.02 |
| `strainThreshold` | растяжение ребра, с которого оно считается разорванным | 0.25 |
| `views` | ракурсы: имя → поворот и подъём в градусах | шесть штук |
| `focusPadding` | запас вокруг цели наведения в долях её радиуса | 1.25 |

## На что смотреть в ответах

- **`layers`.** «Доля» — амплитуда оболочки к амплитуде кожи. «Над сдвигом» — какая часть
  оболочки лежит над сдвигаемой кожей; «смежна» — обязана ли она следовать вообще;
  «должна на» — насколько сдвинута кожа прямо под ней. Оболочка, которая смежна и не следует, —
  это разрыв слоёв.
- **Оболочка может лежать не на коже, а над другой оболочкой** (заплатка шва над шерстью,
  шерсть морды над головой). Тогда смежность с кожей будет нулевой, и спрашивать надо
  относительно её настоящей подложки: `--base fur_belly`, `--base head`.
- **`binding`.** Кости, «сдвинутые лишь частично», — место, где морф двигает одну часть
  кости и бросает другую; там поверхность растягивается, как перчатка на лапе.
- **`empty` и `missing`** ловят молчащие поломки: ползунок есть в файле и не двигает ничего,
  или его нет вовсе, хотя рецепт его обещал.

## Страница в браузере

`mb.py web` собирает один HTML-файл без обращений наружу: открывается с диска, тело
вращается левой кнопкой, колесо — масштаб, правая кнопка — панорама, двойной щелчок — сброс.
Внизу панели — состояние показа тем же JSON, что даёт `--json`, и команда `mb.py render`,
которой этот же кадр получается без окна: всё, что нажато мышью, можно повторить в скрипте.

## Проверки

    python tests\run.py

Фигуры для проверок собираются в памяти, файлов сборки они не трогают; наборы, которым нужен
PyNifly для записи настоящих TRIP и NIF, без него пропускаются с причиной.
